# CI

Infrastructure for stack deployment.

## How to setup DNS

Add following domain to DNS and point them to Docker IP.

- jenkins.com.gecko
- registry.com.gecko
- registry-ui.com.gecko

## How to run

```bash
./run.sh
```

## How to stop

```bash
./stop.sh
```

## UI

- Jenkins - <https://jenkins.com.gecko>
- Docker Registry - <https://registry-ui.com.gecko>
